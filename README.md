# adblocker-esp32-c3
This is a lightweight, dedicated DNS sinkhole running on an ESP32-C3 microcontroller to block ads, trackers and also malware domains accross a local network.
## Features
This adbocker is a very begginer friendly project which runs on a basic standard usb power 24/7.
It is a very budget friendly project as it runs o very less power consumption and the hardwaare needed is also very cheap.
## Hardware required
ESP32-c3 super mini which usually costs around 3 to 5 dollars. ⇒ https://media.printables.com/media/prints/1185ee1c-4ad5-4e96-8810-c70c2b1fe8c8/images/10681260_e7d5a441-fdd6-4fb6-a5c8-38119ca3aa5d_b37cad73-ac2f-412e-9226-cfd020298611/thumbs/inside/1280x960/png/capture-decran-2025-09-15-200303.webp
USB-A Male to USB-C Male adapter costs around 2 to 4 dollars. <img width="447" height="447" alt="image" src="https://github.com/user-attachments/assets/92a8b981-839c-46a9-b55c-b3339b0b3465" />

USB-A power plug (any old power plug is usable here), it can also be connected directly to the usb port in the backside of the WIFI network broadband. (in my case the broadband is having a usb type C port, so I have to get a USB-A to USB-C converter, it costs about 2 to 4 dollars too.)
