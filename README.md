# adblocker-esp32-c3
This is a lightweight, dedicated DNS sinkhole running on an ESP32-C3 microcontroller to block ads, trackers and also malware domains accross a local network.
## Features
This adbocker is a very begginer friendly project which runs on a basic standard usb power 24/7.
It is a very budget friendly project as it runs o very less power consumption and the hardwaare needed is also very cheap.
